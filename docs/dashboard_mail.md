# 首页排行榜与站内邮件

首页保留概览统计，并在下方显示排行榜。宽屏多列展示，窄屏自动单列。六类榜单支持切换；除热搜外，可按模组、地图、材质光影、联机大厅筛选，每页 50 条。无热门榜权限的账号自动使用手游免费榜。概览和排行榜独立加载、报错与重试，切换期间忽略旧请求返回的数据。

CSV 导出按每页 50 条遍历所有选中的榜单与类别，直到读取完接口报告的总数，热搜只读取一次。2026-09-30 验证热门榜 `span=100` 被平台拒绝（`params error`），`span=50` 的首页和后续页正常；导出统一使用 50 条分页，保留全部数据和原始字段。

应用顶部右上角的邮件图标在所有主 Tab 显示。未读数量在进入页面、切换主 Tab、应用回到前台和成功阅读邮件后刷新，前台每两分钟更新一次。图标无可见容器，控件、滚动条和加载状态均使用 OreUI。

邮件页支持标题搜索、邮件类型、只看未读和分页。电脑上列表与正文并排，窄屏点击邮件进入正文，返回键先回列表。HTML 正文直接排版，纯文本保留换行，正文中的网页链接及附件点击后在系统浏览器打开。只请求列表不会改变已读状态；读取正文成功后更新对应邮件的已读状态，失败可重试。

GUI 和无头 CLI 使用同一组模型和接口，命令见 [CLI 文档](cli.md#排行榜与邮件)。

## 排行榜与 Mod 资源详情

有有效资源 ID 的榜单条目可以点击或通过键盘打开详情弹窗，关闭后保留榜单筛选、分页和滚动位置。只有关键词的热搜条目不提供详情入口。正方形资源图标放在标题左侧，展示图列表排除重复的图标。电脑宽屏采用紧凑双列，左侧展示图与组件码，右侧资料与介绍，顶部数据与介绍标题固定，仅简介正文独立滚动；窄屏自动恢复单列滚动，调整窗口大小保留当前图片。支持关闭按钮、Esc 和点击遮罩关闭。

Mod 页面中的 PE / Java 项目也能点击或用键盘打开同一详情，非榜单入口不显示排名。手机与较矮窗口使用单列布局，“资源介绍 / 评论与评分”固定在详情顶部；切到评论后直接显示评分和评论列表，资源统计和展示图留在介绍页。内容独立滚动，切换后从对应内容顶部显示，避免评论入口和正文被展示图挤到屏幕外。

切换“评论与评分”可查看手游资源的总评分、评分人数与最新评论，包含置顶标记、开发者标记、每条评分、正文、时间、点赞和回复数量。评论首次切换时独立加载，每次加载更多增加 20 条，失败可以重试并保留已加载内容；切回介绍再回来不会重复请求。端游当前公开接口未提供评论与评分，显示明确提示。

- 手游：名称、作者、版本、总下载、评分、评分人数、评论数、定价、组件码、展示图和 HTML 介绍。
- 端游：名称、作者、版本、总下载、点赞和组件码。当前验证的端游接口只提供基本资料，介绍可能为空，也不返回展示图或定价。
- 仅展示接口实际提供的字段；缺少价格不推断为免费。组件码优先使用靓号，支持复制。图片可滑动或用箭头切换。
- 加载失败时保留榜单基本信息并提供重试；图片失败单独显示占位。关闭弹窗会关闭详情请求使用的客户端，并忽略晚到的响应。

### 公开详情接口依据

2026-09-29 根据以下公开源码核对协议，并用榜单中的真实资源 ID 验证了无需登录的响应。使用的是官方公开资源接口，没有操作微信、读取微信会话或解包用户的小程序。

- [zbMcLib 的 H5 请求与签名](https://github.com/Ianzb/zbMcLib/blob/b2524bfb957b7c53f9f4d49017159a0a584d7223/zbMcLib/mccn/h5api.py)
- [MCModScanner 的同一 H5 请求实现](https://github.com/GitHub-Zero123/MCModScanner/blob/e04d85b825eb5b8099e5b209ccbf86efa1f690d7/UserManager.cpp)
- [端游请求字段示例](https://github.com/daijunhaoMinecraft/WPFLauncher_Hook/blob/950fb8265ff824ac1419e4cb86f5e8aa6b1d96e5/Mcl.Core/Network/NetClient.cs)

| 平台 | 只读查询接口 | JSON 请求 |
| --- | --- | --- |
| 手游 | `POST https://g79apigatewayobt.nie.netease.com/h5/pe-item-detail-v2` | `channel_id: 5`、字符串 `item_id`、`sign` |
| 端游 | `POST https://x19mclobt.nie.netease.com/item/query/search-by-iid` | 字符串 `item_id` |

手游 `sign` 是 `channel_id=5&item_id={资源ID}&mc#h5page#web` 的 UTF-8 MD5 小写十六进制值。末尾是公开 H5 协议常量，并非账号密钥。两个请求都只设置 JSON Content-Type，独立于开发者平台认证辅助函数，不发送 Cookie、Authorization 或微信凭据。

响应需同时满足 HTTP 200、`code == 0`、`entity` 为对象且资源 ID 匹配；`code == 16` 显示找不到资源。请求超时为 15 秒，接口不可用时不影响榜单。该接口未提供稳定性承诺，后续协议变化可能需要调整。

### 公开评论接口依据

2026-10-02 根据上述固定版本的 [zbMcLib `getUserComment`](https://github.com/Ianzb/zbMcLib/blob/b2524bfb957b7c53f9f4d49017159a0a584d7223/zbMcLib/mccn/h5api.py) 验证手游评论只读接口：`POST https://g79apigatewayobt.nie.netease.com/h5/pe-user-comment`。JSON 请求包含字符串 `item_id`、`length`、`sort_type`、`order` 与 `sign`。签名把前四个字段按键名排序，各拼成 `key=value&`，再追加 `mc#h5page#web` 后取 UTF-8 MD5。仅发送 JSON Content-Type，不使用开发者 Cookie、Authorization 或微信凭据。

- `sort_type=0, order=0` 返回最新优先的普通评论；`sort_type=1` 的已验证响应为推荐顺序。
- `length` 是累计请求的普通评论数，非页码或偏移量。真实资源 `4685624094850259947` 的 `length=20/40` 响应有相同的前 20 条，`length=500` 返回 437 条普通评论和 1 条置顶评论。`order=10` 不会跳过前 10 条，因此应用保持 `order=0`，每次增加 `length` 并替换完整结果。
- `entity.entity_id` 必须匹配请求；`comment_list` 为普通评论，`top_comment_list` 为置顶，`hot_comment_list` 为热门。按置顶、热门、普通顺序合并，用 `comment_id` 去重。
- `master_comment_count` 是主评论总数（包含置顶，不包含回复）。详情的 `comment_count` 还包含回复，不能直接用作主评论列表的分页总数。以上资源验证时分别为 438 和 533。
- 评论字段为 `nickname`、`user_comment`、`stars`、秒级 Unix 时间 `publish_time`、点赞数 `good_num`、回复数 `commented_num`、头像 `head_image` 和开发者标记 `is_developer`。`stars=0` 表示未评分，不能展示为用户给了零星。平均评分与评分人数沿用详情响应的 `stars` 和 `remark_num`，不以评论样本估算。
- 尚未找到已验证的公开端游评论接口。将端游 ID 传给手游接口会得到成功但空的响应，不能据此宣称端游资源没有评论；应用明确提示端游评论暂不支持。

请求具有独立的失败和重试状态，采用与详情相同的 15 秒超时。自动化测试覆盖签名与认证头隔离、累计加载、结束判断、置顶去重、评分与日期解析、空结果、端游隔离及异常响应。
