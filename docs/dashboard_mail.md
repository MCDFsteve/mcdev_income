# 首页排行榜与站内邮件

首页保留概览统计，并在下方显示排行榜。宽屏多列展示，窄屏自动单列。六类榜单支持切换；除热搜外，可按模组、地图、材质光影、联机大厅筛选，每页 50 条。无热门榜权限的账号自动使用手游免费榜。概览和排行榜独立加载、报错与重试，切换期间忽略旧请求返回的数据。

应用顶部右上角的邮件图标在所有主 Tab 显示。未读数量在进入页面、切换主 Tab、应用回到前台和成功阅读邮件后刷新，前台每两分钟更新一次。图标无可见容器，控件、滚动条和加载状态均使用 OreUI。

邮件页支持标题搜索、邮件类型、只看未读和分页。电脑上列表与正文并排，窄屏点击邮件进入正文，返回键先回列表。HTML 正文直接排版，纯文本保留换行，正文中的网页链接及附件点击后在系统浏览器打开。只请求列表不会改变已读状态；读取正文成功后更新对应邮件的已读状态，失败可重试。

GUI 和无头 CLI 使用同一组模型和接口，命令见 [CLI 文档](cli.md#排行榜与邮件)。

## 平台依据

2026-09-27 检查开发者平台公开网页脚本，并用已有会话验证实际响应结构：

- [首页榜单脚本](https://mcdev.webapp.163.com/static/js/4.41b4e7f9fe9357e48755.js)
- [邮件与顶部导航脚本](https://mcdev.webapp.163.com/static/js/1.510cf2827a106c596a4a.js)

接口主机为 `mc-launcher.webapp.163.com`，均复用已有认证：

| 接口 | 用途与参数 |
| --- | --- |
| `GET /square/us_rank_list/` | 热门飙升和热搜，`type/first_type/start/span` |
| `GET /square/rank_list/` | 免费、畅销、下载、点赞榜，参数同上 |
| `GET /mailbox/unread/count` | `data.count` 为未读数量 |
| `GET /mailbox/` | `start/span`，可选 `title/mail_type/have_read`；响应包含 `mail/count/unread_count` |
| `GET /mailbox/{id}` | 读取 `detail`，同时由平台标记这一封为已读；列表中的标题和时间需保留后合并 |

PE 类别编号依次为模组 2、地图 1、材质光影 3、联机大厅 6；PC 为 3、5、4、11；热搜的 `first_type=0`。热门/热搜由 `users/me` 的 `can_us_rank` 控制。榜单不同响应的排名、标题和变化量统一展示；接口未返回下载量等数值时不显示虚构的零。

## 验证

自动化测试覆盖类别与接口映射、筛选和分页、账号权限、概览失败隔离、延迟响应切换、窄屏与宽屏布局、邮件 HTML 渲染、读取失败重试、未读数量刷新以及 CLI JSON 输出。生产会话仅查询榜单、未读数量、邮件列表和原本已读邮件的正文；没有为了测试改变未读邮件的状态。
