# 1.6.0 更新日志

本次更新汇总上次发布 `v1.5.0+8` 以来的代码变化：新增物品信息显示、关闭声音和 AI 控制当前玩家，修复模组 UUID 变化后无法测试的问题，支持网易登录安全验证，并首次提供 Windows 安装程序。

## 物品信息显示

- “开发 → 启动游戏”新增 **物品信息显示** 选项，默认关闭，每个测试页单独保存。
- 勾选后，测试世界右上角实时显示准星指向的方块或生物，第二行是 identifier，方块还带 aux，便于在上线前发现漏配的中文文本。
- 白色表示已有中文；黄色表示有文本但不含汉字，例如 `zh_CN.lang` 里填的还是英文；红色“未配置中文”会直接显示缺失的语言键，把这个键加进 `zh_CN.lang` 即可。只写在 `en_US.lang` 也算缺失，中文环境不会回退到英文。
- 方块名称按 identifier 和 aux 读取，能区分 aux 变体；没有对应物品的方块使用 `tile.<identifier>.name`。玩家显示玩家名，不做检查。
- 该功能是随测试启动的内置模组，只读取客户端状态，不修改世界，也不写入你的项目。局域网访客沿用房主的设置。

## 模组 UUID 变化后继续测试

- 修复导入后 `manifest.json` 的 UUID 发生变化（例如打包时重置）时，启动测试报“源文件已变化或无法访问，请重新导入”的问题。
- 启动测试前按项目目录读取当前的清单，自动采用新的 UUID、名称和版本，并保留所有测试页的项目勾选。无需重新导入。

## 关闭声音

- 新增 **关闭声音** 选项，支持 `3.10.0.420447 x64`。通过 DLL 关闭游戏声音，重启游戏后生效。

## AI 控制当前玩家

- `3.10.0.420447` 新增 **允许 AI 控制当前玩家** 选项。测试世界可通过本地 JSON 接口读取玩家、摄像机、准星、声音和界面事件，并执行移动、转向、挖掘等动作。
- 接口只绑定本机地址，每次启动使用独立令牌，不接受 Python 源码或游戏命令。完整协议、限额和验证边界见 [AI 控制说明](https://github.com/MCDFsteve/mcdev_income/blob/v1.6.0%2B9/docs/ai-game-control.md)。

## 登录

- 网易要求安全验证（`ret=447`）时，客户端打开内置 WebView 小窗口显示官方验证码，完成后自动继续登录。命令行随后可共用该会话。

## Windows 安装程序

- Windows 发布新增 `-windows-x86_64-setup.exe` 安装程序：简体中文界面，默认为当前用户安装，无需管理员权限，可在安装时选择为所有用户安装，并可创建桌面快捷方式。
- 原有的 zip 绿色版继续提供。安装和卸载都不会改动开发目录、登录状态和测试存档。

## 文档与发布验证

- 补充物品信息显示、AI 控制和登录安全验证的说明。
- 物品信息显示已在 Windows 真机的 `3.10.0.420447`（OpenGL）上验收：原版方块与朝向变体、有中文、无文本、英文文本、原版生物、无文本的自定义生物和无目标都符合预期，截图确认显示在右上角。macOS 和其他游戏版本未做实机验证。
- Flutter 回归 460 项通过、6 项跳过，物品信息 Python 测试 18 项通过。4 项原有的开发页与项目详情组件测试仍失败，不计入通过数量。
