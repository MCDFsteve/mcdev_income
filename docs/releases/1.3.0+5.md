## 更新内容

- **多测试页与多窗口**：开发页支持新建、切换和关闭测试 Tab，至少保留一个。每页独立保存游戏版本、模组选择、测试设置和存档，启动一页后仍可操作其他页。游戏窗口及 Dock 名称包含对应模组，便于区分。
- **局域网多人测试**：每页新增「局域网测试」，设置玩家名字和史蒂夫／艾利克斯皮肤后，打开独立窗口直接加入该页的世界；可以反复添加，启动器不设窗口数量上限。「玩家列表」显示实际在线玩家及连接状态，可单独关闭测试玩家窗口。退出房主会清理该页所属访客，其他测试页不受影响。
- **OreUI 窗口与 macOS 菜单**：管理器和测试游戏采用自绘顶栏，保留系统红绿灯。游戏菜单提供暂停、物品栏、聊天、命令、切换视角、全屏及 F1–F12，方便使用 Mac 键盘操作。
- **新存档与种子**：一级页面提供「使用新存档」。勾选后每次启动创建独立存档，并可填写种子；取消勾选后继续最近一次创建成功的存档。
- **桌面界面修复**：Tab 改用带容器的单选按钮，选中时绿色高亮并显示底部横线；关闭按钮紧贴 Tab，添加按钮也使用容器。修复深色模式对比度和游戏模式、皮肤、渲染器选择按钮之间的空隙，恢复选择控件默认的相连布局。
- **联机与重启稳定性**：修复访客皮肤与玩家初始化、旧玩家名字截断造成的设置读取失败、端口释放竞态，以及短暂连接信息延迟被误判为房主退出的问题。访客使用房主本次启动时已装配的模组副本，确保同一世界中的模组一致。

## 使用说明

本地游戏开发功能仅在 Apple 芯片 macOS 显示，共用客户端已有登录；Wine 与游戏仍需首次在线下载，客户端不内置游戏。

本次局域网适配仅支持 **3.10.0.420447 Haldra x64**。请先启动测试世界并等待加载完成，再添加测试玩家。其他版本会显示尚未适配的提示。玩家名字最多 16 个 UTF-8 字节，通常相当于 16 个英文字符或 5 个常用汉字；同一世界不能使用重复名字。窗口数量还会受到游戏容量与机器资源限制，多开帧率取决于场景和硬件。

已在 3.10.0.420447 OpenGL 实机验证三人同服、史蒂夫与艾利克斯纹理及手臂模型、行为包生效、单独退出、重新加入，以及房主退出后的访客清理。灵动视效继续作为实验功能提供，本次不包含其画质问题修复。

关闭游戏或测试页前，请先在游戏内保存。创建新存档后，取消「使用新存档」会继续最近一次存档；本次仍未提供历史存档选择界面。
