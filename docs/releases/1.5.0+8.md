# 1.5.0 更新日志

本次更新汇总上次发布 `v1.4.0+7` 以来的代码变化，新增 Python 热重载，并修复 macOS Wine 补丁校验和游戏加载后卡死的问题。

## Python 热重载

- “开发 → 启动游戏”区域新增 **Python 热重载** 按钮，位于“查看日志”右侧，与其他测试操作放在一起；窄窗口中日志与重载按钮一起换行。
- 对已校验的 `3.10.0.420447 x64`，启动测试时自动注入独立 DLL，直接在游戏现有 Python 线程中执行重载。无需启动 MCS 编辑器。
- 修改并保存源项目中的 Python 后，可更新客户端和服务端已加载的函数及类方法，保留已有系统实例、实例属性和已注册的回调。
- 应用前由游戏内的解释器检查整个修改批次。语法错误会显示详细日志，修正后可重试；没有源码变化时跳过操作。
- 只将 `.py` 修改同步到测试装配副本，清理对应字节码缓存并保留原有模组日志捕获包装。文件同步不改写源项目。
- 各测试会话及世界的重载请求独立；退出、切换世界或重载超时会终止旧操作。退出时等待文件同步撤销完成，防止影响下一次启动。
- 第一版只处理 Python，行为 JSON 和资源包仍需重新启动测试。删除或重命名脚本、改变类结构或执行阶段失败也需要重启；构造器和系统初始化不会自动重跑。模块顶层代码会再次执行。
- 局域网玩家正在加入或在线时禁用重载；成功重载后需要重启测试再添加局域网玩家。

## macOS Wine 修复

- 修复不同 macOS 版本的临时签名元数据差异导致 Wine 补丁被误判为损坏的问题。继续验证实际签名及可执行内容，兼容已知的签名布局变化，并保留损坏文件的拒绝处理。
- 修复部分 Apple 芯片 Mac 在游戏加载后短暂正常、随后画面和操作一起卡住的问题：为缺少接口编号的 IPv6 局域网发现数据包选择可用网络接口。
- 网络修复优先保留已经设置的接口，仅处理相关局域网发现流量，与输入和游戏顶栏组件共同加载；网络组件缓存损坏时自动修复。
