# 1.6.3 更新日志

开发模式现在支持创建超平坦地图。

## 地图类型

- 勾选“使用新存档”后，可通过“地图类型”下拉框选择“无限”或“超平坦”，默认“无限”。
- 每个测试标签独立保存地图类型，重开启动器后仍会恢复选择。
- 地图类型仅用于创建新存档；继续已有存档时保留原有地形，不转换或覆盖旧世界。
- 游戏运行、准备启动、仅打开主菜单及保存选择期间，相关控件会禁用，避免误操作。

## 发布验证

- 60 项相关自动化测试通过，覆盖配置生成、设置持久化、测试标签隔离、保存失败处理，以及明暗主题和窄屏布局。
- Windows 实机（`3.10.0.448891`，OpenGL）验证新建超平坦世界成功；退出后继续相同存档仍保持超平坦。两次运行均确认世界持续运行且无崩溃记录，并检查存档的 `Generator` 为 `2`。
