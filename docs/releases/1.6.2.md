# 1.6.2 更新日志

本次更新修复 Windows 上启动测试游戏时，游戏窗口偶尔没有标题栏，或者分成两个窗口的问题。

## Windows 游戏窗口

- 修复游戏窗口偶尔盖住顶栏，看起来没有标题栏的问题。
- 修复偶尔出现两个窗口的问题：一个是带标题栏的黑屏，一个是没有标题栏的游戏画面，任务栏也显示两个图标。
- 原因是游戏在加载期间仍会调整自己的窗口，而启动器只在第一次嵌入时摆放一次。现在启动器会持续检查游戏窗口的实际位置和状态，发现不对就立即纠正，不再需要拉伸窗口来恢复。
- 游戏重建窗口时会自动嵌入新窗口；游戏运行中个别检查失败只会在下一次重试，不会关闭游戏。

## 发布验证

- 在 Windows 真机（`3.10.0.448891`，OpenGL）上主动把嵌入后的游戏窗口挪到顶栏位置、或拆成独立窗口：修复前启动器不会纠正，修复后 1 秒内恢复。正常启动流程在修复前后共 14 次启动中均保持嵌入。
- 新增 `test/live_windows_window_smoke.dart`，在 Windows 上反复启动并检查窗口嵌入，可用于以后的回归验证。
- 本次未改动 Dart 业务代码。
