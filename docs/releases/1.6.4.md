# 1.6.4 更新日志

本次更新修复登录密码与会话 Cookie 以明文保存在本地配置文件中的安全问题（[#4](https://github.com/MCDFsteve/mcdev_income/issues/4)），彻底移除密码本地持久化，并将登录会话凭证迁移至各操作系统的原生安全凭据库。

## 凭据安全与会话存储

- **不再保存登录密码：** 登录密码仅在当次登录请求的内存中使用，不再落盘或写入任何存储。移除登录页“保存密码用于自动刷新凭证”选项，CLI 移除 `auth login --remember` 与 `auth refresh` 命令。
- **会话凭证转入系统安全存储：** `state.json` 与 `SharedPreferences` 仅保存主题、收益预设、本机草稿等非敏感设置，不再写入任何账号密码、Cookie 或 Token。会话凭证按状态目录隔离，改由系统原生安全凭据库保存：
  - **Windows：** Windows 凭据管理器（无交互凭据集的远程 SSH 会话自动切换至当前用户级 DPAPI 加密）。
  - **macOS / iOS：** 系统钥匙串（Keychain）。
  - **Linux：** Secret Service（GNOME Keyring / KWallet）；无运行中密钥环的无桌面环境请通过 `MCDEV_COOKIE` 环境变量传入会话。
  - **Android：** `AndroidKeyStore`（AES-256-GCM）。
- **旧版本明文残留自动清除：** 升级后首次启动桌面端、移动端或运行无头 CLI 时，会自动将原本地存储中的有效会话迁入系统安全存储，并立即从 `state.json`、`SharedPreferences` 及旧版 macOS 容器配置中永久删除 `login_password_v1`、`login_cookie_cache_v1`、`login_email_v1` 等历史明文字段。
- **安全建议：** 若此前在旧版本勾选过保存密码且使用环境存在不可信程序风险，升级后建议修改一次开发者账号密码。

## 会话过期提示

- 会话到期后打开软件会自动弹出“登录已过期”提示框，同时擦除已失效的本地 Cookie / Token；点击“去登录”可直接打开登录页并自动回填原账号邮箱，重新登录后主页与设置页自动刷新。
- 使用期间若平台接口返回 HTTP `401`（会话在服务端提前失效），同样会自动擦除失效凭证并弹窗提示重新登录。

## 发布验证

- 55 项登录、CLI、系统安全存储与会话过期弹窗自动化测试在 macOS 与 Windows 实机双端全部通过，覆盖 macOS 钥匙串与 Windows 原生安全存储的读写、超长载荷分片、更新与删除、目录隔离、历史明文迁移擦除及过期弹窗交互。
- Windows Release 构建生成的 `minecraft_developer_manager.exe` 完成端到端复现验证：对包含明文密码与会话 Cookie 的旧版 `state.json` 执行 `--headless auth status` 后，会话无缝迁移并识别为已登录，磁盘 `state.json` 中的明文密码、Cookie 与邮箱被彻底清除。
