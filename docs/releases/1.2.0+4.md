## 更新内容

- Apple 芯片 Mac 新增「开发」页：共用现有账号登录，按需下载 Wine 和游戏，支持配置、迁移数据目录，导入本地模组并启动测试。客户端不内置游戏文件。
- 游戏版本支持完整版本清单、正式版与测试版筛选、多版本安装共存和启动版本选择；桌面布局突出启动入口，进度显示不再挤压页面。
- 同一项目的行为包与资源包合并显示、一起启用。本地项目名称使用 `manifest.json` 中的标题，优先行为包标题，刷新时同步标题修改；各包信息可在详情弹窗查看。
- 测试设置加入受支持版本的 OpenGL / 渲染龙切换、灵动视效实验选项、图形性能优化，以及 60 帧限制开关。关闭限制后允许游戏运行到当前设备和场景能够达到的帧率。
- 日志弹窗支持高亮、筛选、可开关的自动滚动、复制和导出。
- 「显示开发控制台」与「Shift + Command 切换全屏」默认关闭；不支持图形优化的版本隐藏该选项，避免全屏快捷键与截图冲突。
- 测试游戏窗口加入独立的 macOS 应用身份和国际版基岩版官方图标，便于识别与读取画面。修复艾利克斯选择后仍显示史蒂夫的问题，已在 3.10 渲染龙中验证纹理与细手臂模型。
- 首页作品详情支持查看完整资源信息，排行榜可导出；修复资源文件替换时的上传签名与请求数据问题。
- 发布附件名称统一包含客户端版本、操作系统和架构。Android 分别提供 `armeabi-v7a`、`arm64-v8a` 和 `x86_64` APK；macOS 包按实际二进制架构命名。

## 使用说明

本地游戏开发功能仅在 Apple 芯片 macOS 显示，Wine 和游戏需首次在线下载；图形补丁与灵动视效选项按已适配的游戏版本开放。灵动视效仍为实验功能，帧率随场景和设置变化。

桌面发布包请保留完整运行库和资源文件。macOS 的 `arm64-x86_64` 附件包含两种客户端架构；本地开发入口仍限 Apple 芯片。iOS 附件为未签名应用，需要自行签名安装。Android 请根据设备架构选择 APK，常见新款设备使用 `arm64-v8a`。
