# 1.6.1 更新日志

本次更新取消关闭声音和灵动视效的版本限制：两个功能不再绑定 `3.10.0.420447`，Windows 也可以使用灵动视效了。

## 灵动视效

- 只要选择渲染龙（3.9 及以上）就可以开启灵动视效，不再限定具体游戏版本。
- **Windows：** 修复灵动视效开关一直不可用的问题。游戏原生支持，启动时写入 `graphics_mode:2`，退出后恢复，不需要补丁。
- **macOS：** Metal 适配改为运行时按代码特征定位，不再依赖固定地址和游戏文件哈希。`3.9.0.401155` 首次可以在 Mac 上使用渲染龙和灵动视效。
- 特征无法定位时，渲染日志会写明是哪一条，并在界面提示适配未能激活。

## 关闭声音

- 改为把游戏设置中的主音量调成 0，退出后恢复，所有游戏版本都能使用。
- 移除原来的声音 DLL 和版本校验。
- 游戏运行时手动调高音量，声音会恢复；退出后仍还原为启动前的音量。

## 开发者工具

- 新增 `tools/renderer/scan_signatures.ps1`，在 Windows 上打开游戏后运行，可检查新版本的特征是否仍能定位。

## 文档与发布验证

- 灵动视效在 Windows 真机的 `3.9.0.401155`、`3.10.0.420447`、`3.10.0.448891` 上通过：设置在运行中生效，退出后恢复。其中 `3.9.0.401155` 和 `3.10.0.448891` 的游戏调试信息确认进入 `PBR` 管线。
- macOS（Apple M4）上验证了 `3.9.0.401155` 和 `3.10.0.420447`：游戏调试信息显示 `D3D11 PBR D3D_SM50`，渲染日志确认 D3D11 后端和灵动视效支持，局域网补丁正常。`3.10.0.448891` 在 Windows 上确认特征可定位，未在 Mac 上运行。
- 关闭声音的新实现由单元测试覆盖，未在真实游戏里测试静音效果。
- Flutter 回归 454 项通过、6 项跳过，Python 测试 44 项通过。4 项原有的开发页与项目详情组件测试仍失败，不计入通过数量。
